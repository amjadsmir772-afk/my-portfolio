EasyShop - مشروع متجر إلكتروني تعليمي
=====================================

فكرة المشروع: متجر إلكتروني لبيع الهواتف والحواسيب والإكسسوارات وبعض المنتجات المنزلية.
المشروع واجهة عميل فقط ولا يحتوي على أي صفحة أو حساب أو واجهة للمدير.

التقنيات:
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

الصفحات:
index.html - الرئيسية
about.html - من نحن
services.html - الخدمات
products.html - المنتجات
product.html - تفاصيل المنتج
contact.html - اتصل بنا
login.html - تسجيل الدخول
register.html - إنشاء حساب
profile.html - حساب العميل والطلبات
cart.html - سلة المشتريات
checkout.html - إتمام الطلب
success.html - نجاح الطلب
calculator.html - حاسبة سعر المنتجات

متطلبات الملزمة المطبقة:
1. التعامل مع عناصر HTML: getElementById و querySelector و querySelectorAll و innerHTML و textContent و style.
2. Events متعددة: click و dblclick و mouseover و mouseout و input و change و submit.
3. Form Validation للاسم والبريد والهاتف وكلمة المرور والحقول المطلوبة.
4. إظهار وإخفاء كلمة المرور.
5. Slider للصور مع السابق والتالي والتغيير التلقائي.
6. تغيير محتوى الصفحة باستخدام JavaScript (عرض المزيد/إخفاء المزيد).
7. Modal لعرض تفاصيل المنتج والتقييم.
8. Search للبحث عن المنتجات.
9. Filter حسب الفئة.
10. Arrays لتخزين المنتجات والبيانات.
11. Objects لتمثيل المنتجات والمستخدمين والطلبات.
12. Loops وforEach لمعالجة البيانات وعرض المنتجات.
13. Conditions باستخدام if وelse وغيرها.
14. الساعة والتاريخ مع تحديث مستمر.
15. Dark Mode مع حفظ الاختيار.
16. زر العودة إلى الأعلى.
17. رسائل تنبيه داخل الصفحة Toast.
18. آلة حاسبة لحساب سعر المنتجات والكمية والخصم.
19. LocalStorage للمستخدمين والسلة والمفضلة والتقييمات والطلبات والثيم.
20. Countdown باستخدام setInterval.

الملزمة تشترط تنفيذ 15 وظيفة JavaScript على الأقل من أنواع مختلفة، واستخدام Arrays وObjects وConditions وLoops وFunctions وEvents وDOM وLocalStorage، إضافة إلى 5 أحداث مختلفة على الأقل. هذه العناصر موجودة في المشروع وموزعة على الصفحات.

الصور:
الهواتف والحواسيب الرئيسية تستخدم روابط صور مباشرة، بينما بعض المنتجات الأخرى تستخدم صوراً محلية داخل مجلد images.

ملاحظة أكاديمية:
الملزمة تمنع استخدام jQuery أو مكتبات JavaScript لتنفيذ الوظائف الأساسية، لذلك الوظائف التفاعلية في المشروع مكتوبة بـ Vanilla JavaScript.
